# ปรับปรุง UX/UI ฟิลด์ “ส่วนงาน/ช่วง (ไม่จำเป็น)” ให้ใช้งานง่ายและเข้าใจง่ายขึ้น

ปรับปรุงฟิลด์ “ส่วนงาน/ช่วง (ไม่จำเป็น)” ใน TaskModal ให้มี UI ที่ชัดเจนกว่าเดิม โดยเปลี่ยน label และ placeholder ให้เป็นภาษาไทยที่เข้าใจง่าย และเพิ่มตัวอย่างเพื่อให้ Junior ใช้งานได้ทันที

## การเปลี่ยนแปลงที่เสนอ

- **Label**: “ส่วนงาน / ช่วง (ไม่จำเป็น)” → **“Phase / ส่วนงาน (แบ่งตามขั้นตอน)”**
- **Placeholder**: “Part / Phase” → **“เช่น Design, Development, Testing, UAT”**
- **Icon**: คง Layers icon ไว้เพราะเหมาะกับการจัดกลุ่มงาน

## เหตุผล
- “Phase / ส่วนงาน” ใช้คำศัพท์ที่ทีมคุ้นเคยในการจัดการโปรเจค
- “(แบ่งตามขั้นตอน)” อธิบายว่าใช้ทำอะไรได้ชัดเจนกว่า “(ไม่จำเป็น)”
- ตัวอย่างช่วยให้ผู้ใช้ใหม่เข้าใจทันทีว่าควรกรอกอะไร
- ยังคงการทำงานของ datalist (auto-complete) ไว้เพื่อความสะดวก
