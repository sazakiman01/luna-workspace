# Commit Standards Review Plan
รีวิวไฟล์ `.windsurf/rules/commit-standards.md` เชิงเนื้อหาและความชัดเจน เพื่อให้มั่นใจว่า AI commit feature สร้างข้อความตาม Conventional Commits ได้ตรงมาตรฐาน

1. อ่าน directive ทั้งหมดเพื่อตรวจสอบความครบถ้วน: purpose, execution rules, allowed types, และ subject rules
2. ตรวจสอบว่ามีคำอธิบายข้อสำคัญครบ เช่น โครงสร้าง, ประเภท commit, guideline การเขียน subject/body
3. สรุปผลรีวิวพร้อมข้อเสนอแนะ (ถ้ามี) เช่น การเพิ่ม scope guidance, ตัวอย่าง commit, หรือการกล่าวถึงภาษาไทย/อังกฤษ
