# ปรับปรุงคำว่า “เลขที่งาน” และ “ลำดับที่” ให้ชัดเจนและไม่สับสน

แก้ไข UI ใน TaskModal ให้ผู้ใช้เข้าใจความแตกต่างระหว่าง “เลขที่งาน” (taskNo) และ “ลำดับที่” (order) โดยเปลี่ยนคำและเพิ่มคำอธิบายเล็กน้อยใน label และ placeholder เพื่อลดความสับสนแต่ยังคงฟังก์ชันเดิมไว้

## การเปลี่ยนแปลงที่เสนอ

- **เลขที่งาน (taskNo)** → เปลี่ยนเป็น **“รหัสงาน”** และเพิ่ม placeholder ว่า “เช่น DEV-01, PH2-03”
- **ลำดับที่ (order)** → เปลี่ยนเป็น **“ลำดับการแสดง”** และเพิ่ม placeholder ว่า “เรียงใน Roadmap (0,1,2…)”

## ไฟล์ที่แก้ไข
- src/features/delivery/TaskModal.jsx (บรรทัด label และ placeholder)

## เหตุผล
- “รหัสงาน” สื่อถึงการอ้างอิงภายนอกได้ดีกว่า “เลขที่งาน”
- “ลำดับการแสดง” บอกให้เข้าใจว่าควบคุมตำแหน่งใน Roadmap ไม่ใช่เลขลำดับทางการ
- คำอธิบายใน placeholder ช่วยให้ Junior ใช้ได้ทันที
