# ปรับปรุงภาษา Agent Luna ให้เป็นภาษาไทยมาตรฐาน

แผนนี้มีวัตถุประสงค์เพื่อปรับปรุง agent luna ให้ตอบเป็นภาษาไทยหลัก ใช้ภาษาที่เข้าใจง่ายสำหรับระดับ junior developer และเป็นไปตามมาตรฐานของทีม Go-Flow

## ขอบเขตการทำงาน

### ไฟล์ที่ต้องปรับปรุง (ลำดับความสำคัญ)
1. **SKILL.md** - สมองของ agent (สำคัญที่สุด)
2. **README.md** - คู่มือการใช้งาน
3. **assets/code-review-template.md** - แม่แบบรีวิวโค้ด
4. **assets/learning-report-template.md** - แม่แบบรายงานการเรียนรู้
5. **assets/agent-report-template.md** - แม่แบบรายงาน agent
6. **assets/discovery-template.md** - แม่แบบบันทึกการค้นพบ
7. **references/mentorship-guide.md** - คู่มิการ mentorship
8. **references/skill-standards.md** - มาตรฐาน skill
9. **references/team-guide.md** - คู่มือทีม
10. **references/frontend-checklist.md** - เช็คลิสต์ frontend

## รูปแบบภาษาที่ใช้

### หลักการ
- **ภาษาหลัก**: ภาษาไทย 100%
- **ระดับภาษา**: เป็นกันเอง เข้าใจง่าย เหมาะกับ junior developer
- **คำนำ**: ใช้ "ครับ/ค่ะ" ตามบริบท
- **ประโยค**: สั้น กระชับ ชัดเจน
- **ศัพท์เทคนิค**: ใช้ภาษาอังกฤษเฉพาะที่จำเป็น และมีคำอธิบายภาษาไทย

### ลักษณะบุคลิก
- **เป็นพี่/ผู้สอน**: ให้คำแนะนำอย่างใจดี
- **จริงจัง**: มุ่งมั่นทำงานให้ดี
- **เข้าใจง่าย**: อธิบาย concept ซับซ้อนให้เข้าใจ
- **สนับสนุน**: ให้กำลังใจและแนะนำทางออก

## สิ่งที่ต้องปรับปรุงในแต่ละไฟล์

### 1. SKILL.md
- แปลส่วนที่เป็นภาษาอังกฤษทั้งหมด
- ปรับคำสั่งให้เป็นภาษาไทยที่ชัดเจน
- เพิ่มตัวอย่างการใช้งานเป็นภาษาไทย
- ทำให้ workflow เข้าใจง่ายขึ้น

### 2. README.md
- ปรับส่วนที่ยังเป็นภาษาอังกฤษ
- ทำให้ตัวอย่างคำสั่งเป็นภาษาไทยล้วน
- เพิ่ม best practices เป็นภาษาไทย

### 3. Templates (assets/)
- แปลหัวข้อและคำแนะนำเป็นภาษาไทย
- ทำให้รูปแบบการกรอกเข้าใจง่าย
- เพิ่มคำอธิบายในส่วนที่ซับซ้อน

### 4. References
- แปลคู่มือทั้งหมดเป็นภาษาไทย
- ทำให้ตัวอย่างโค้ดมีคำอธิบายภาษาไทย
- ปรับรูปแบบให้เข้าใจง่ายสำหรับ junior
