# แก้ไขข้อความภาษาญี่ปุ่นในหน้า Edit Project

## สรุปปัญหา
พบข้อความภาษาญี่ปุ่นปนอยู่ในหน้า edit project ส่วนของการคำนวณ VAT ที่บรรทัด 806 ในไฟล์ `src/features/projects/NewProjectModal.jsx`

## รายละเอียดที่ต้องแก้ไข
- **ไฟล์**: `src/features/projects/NewProjectModal.jsx`
- **บรรทัด**: 806
- **ข้อความปัญหา**: "กรอกงบประมาณ ระบบจะคิด VAT ให้自動"
- **ข้อความที่ต้องแก้**: "自動" (ภาษาญี่ปุ่น)
- **ข้อความที่เปลี่ยนเป็น**: "อัตโนมัติ" (ภาษาไทย)

## การแก้ไข
เปลี่ยนข้อความจาก:
```jsx
กรอกงบประมาณ ระบบจะคิด VAT ให้自動
```

เป็น:
```jsx
กรอกงบประมาณ ระบบจะคิด VAT ให้อัตโนมัติ
```

## ผลลัพธ์ที่คาดหวัง
- ข้อความเป็นภาษาไทย 100% ตามหลักการของระบบ
- ผู้ใช้งานเข้าใจได้ง่ายขึ้น
- ไม่มีข้อความภาษาอื่นปนอยู่ใน UI
