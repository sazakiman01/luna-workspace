# เพิ่มวันหยุดปี 2569 (2026) จากรูป

แผนการเพิ่มวันหยุดปี 2569 (2026) ทั้งหมดจากรูปปฏิทินที่ให้มา โดยเพิ่มผ่าน code/database โดยตรงและอัปเดต template วันหยุดไทยใน UI ใหม่

- 14 เมษายน: วันสงกรานต์  
- 15 เมษายน: วันสงกรานต์

- 31 ธันวาคม: วันสิ้นปี

## ขั้นตอนการทำงาน

### 1. เพิ่มวันหยุดใน MOCK_HOLIDAYS (mockData.js)
- แทนที่ MOCK_HOLIDAYS ปัจจุบันด้วยรายการวันหยุดปี 2026 ทั้งหมด (16 วัน)
- ใช้โครงสร้าง: `{ id: 'hX', name: 'ชื่อวันหยุด', date: '2026-MM-DD', type: 'public' }`

### 2. อัปเดต THAI_HOLIDAY_TEMPLATES (HolidayManagerModal.jsx)
- แก้ไข template ให้ตรงกับวันหยุดปี 2026 จากรูป
- อัปเดตวันที่ defaultDate ให้ถูกต้อง (เช่น มาฆบูชา 03-03, วิสาขบูชา 05-12, อาสาฬหบูชา 07-28)
- เพิ่มวันหยุดพิเศษที่ไม่มีใน template เดิม (วันตรุษจีน, วันฉัตรมงคล, วันนวมินทรมหาราช)

### 3. สร้าง script เพิ่มข้อมูลใน Firebase (ถ้าจำเป็น)
- สร้าง utility function สำหรับ batch add holidays ลง Firestore
- ใช้ writeBatch เพื่อความมั่นคงและประสิทธิภาพ

## โครงสร้างข้อมูลที่ใช้

```javascript
// MOCK_HOLIDAYS structure
{
  id: 'hX',                    // Unique ID
  name: 'ชื่อวันหยุด',        // Thai name
  date: '2026-MM-DD',         // ISO date format
  type: 'public'              // All as public holidays
}

// THAI_HOLIDAY_TEMPLATES structure  
{
  name: "ชื่อวันหยุด",
  defaultDate: "MM-DD",      // Month-Day format
  type: "public" | "religious",
  fixed: true | false        // Fixed date or movable
}
```

## ผลลัพธ์ที่คาดหวัง

1. **Database**: มีวันหยุดปี 2026 ทั้งหมด 16 วัน (รวมช่วงสงกรานต์ 3 วัน)
2. **UI Template**: Tab "วันหยุดไทย" แสดง template ที่ถูกต้องตามปี 2026
3. **Consistency**: ข้อมูลระหว่าง mock data และ Firebase ตรงกัน
4. **User Experience**: สามารถใช้งาน Holiday Manager Modal ใหม่ได้เต็มประสิทธิภาพ

## หมายเหตุ

- วันหยุดทั้งหมดจะถูกจัดประเภทเป็น 'public' (วันหยุดพอ) ตามที่กำหนด
- ช่วงวันหยุดจะเพิ่มแยกเป็นรายวัน (13-15 เมษายน = 3 records)
- ไม่ต้องแยกประเภท substitution/observance เพราะมองเป็นวันหยุดทั้งหมด
