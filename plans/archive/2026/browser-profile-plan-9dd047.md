# วิธีเปิด 2 โปรไฟล์/เซสชันในเบราว์เซอร์เดียว
สรุป: คู่มือย่อแสดงวิธีสร้าง/ใช้โปรไฟล์แยก (Chrome) และ Guest Mode เพื่อให้ session กับ localStorage ไม่ปนกันสำหรับการทดสอบ

1. ใช้ Chrome Profiles
   - คลิกไอคอนโปรไฟล์มุมขวาบนของ Chrome → เลือก “Add” หรือ “+”
   - ตั้งชื่อ/สี แล้วเลือก “Continue without an account” เพื่อสร้างโปรไฟล์ใหม่ (หรือ login บัญชี Google อื่นก็ได้)
   - เปิดหน้าเว็บ (localhost) ในทั้งสองโปรไฟล์ แต่ละโปรไฟล์จะมี localStorage แยกกัน
2. ใช้ Chrome Guest Mode
   - คลิกไอคอนโปรไฟล์ → เลือก “Guest” เพื่อเปิดหน้าต่าง Guest ที่ไม่เก็บข้อมูลร่วมกับโปรไฟล์หลัก
   - หน้าต่าง Guest ปิดแล้วข้อมูลหายทั้งหมด เหมาะกับการทดสอบ session สั้นๆ
3. ใช้หลายเบราว์เซอร์
   - เปิด Chrome สำหรับ session แรก และ Edge/Firefox สำหรับ session ที่สอง (localStorage คนละชุดโดยธรรมชาติ)
   - วิธีนี้ง่ายหากไม่อยากตั้งโปรไฟล์ แต่ต้องแน่ใจว่า extension / devtools settings ที่จำเป็นมีในทั้งสองเบราว์เซอร์
4. เคล็ดลับการทดสอบ
   - ใส่ label หรือสี theme ต่างกันให้แต่ละโปรไฟล์ จะได้ไม่สับสนว่า session ไหนเป็น user ใด
   - หากต้องการมากกว่า 2 session สามารถสร้างโปรไฟล์เพิ่มได้เรื่อยๆ หรือเปิด Guest หลายหน้าต่างพร้อมกัน
