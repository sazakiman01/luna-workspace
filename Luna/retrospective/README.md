# Luna Weekly Retrospective

ไฟล์ในโฟลเดอร์นี้คือ weekly retrospective ของลูน่า เพื่อรีวิวการเรียนรู้และปรับปรุงตัวเองอย่างต่อเนื่อง

## 📅 ความถี่

- **ทุกสัปดาห์** (หรือเมื่อพี่แมนสั่ง)
- **Filename:** `YYYY-Www.md` (เช่น `2026-W17.md` สำหรับสัปดาห์ที่ 17 ของปี 2026)

## 📝 Template

```markdown
# Luna Weekly Retrospective - Week WW (YYYY-MM-DD → YYYY-MM-DD)

## 🎯 สรุปงานสัปดาห์นี้
- [Task สำคัญที่ทำเสร็จ]
- [Repo ที่เข้าไปทำงาน]
- [Role ที่เรียกใช้]

## ✅ What went well
- [สิ่งที่ทำได้ดี — พี่แมนพอใจ]

## ⚠️ What went wrong
- [สิ่งที่ทำผิด / พี่แมนต้อง correct]
- [Anti-patterns ที่เจอ → บันทึกใน insights.md]

## 🔍 Patterns confirmed this week
- [Pattern ที่ evidence เพิ่มขึ้น]
- [Pattern ที่ย้ายจาก hypothesis → insights]
- [Pattern ที่ย้ายจาก insights → preferences]

## 💡 New hypotheses
- [Pattern ใหม่ที่สังเกตได้ในสัปดาห์นี้]

## 🗑️ Patterns to review (outdated?)
- [Preferences/insights ที่อาจไม่ valid แล้ว]
- [Hypothesis ที่ค้างเกิน 4 สัปดาห์ → พิจารณาลบ]

## 🚫 Anti-patterns ที่เจอ
- [สิ่งที่ทำผิด → บันทึกใน insights.md]

## 🎯 Next week focus
- [สิ่งที่จะ improve สัปดาห์หน้า]
- [Pattern ที่จะจับตา]

---
*สร้างโดย: Luna | Reviewed by: พี่แมน*
```

## 🔄 Process การทำ Retrospective

1. **อ่าน `hypothesis.md`** — มีอะไรค้างบ้าง?
2. **อ่าน `insights.md`** — มี pattern ที่ evidence ถึง 3 แล้วไหม? (→ ย้ายไป preferences.md)
3. **อ่าน `preferences.md`** — มีอะไร outdated ไหม?
4. **อ่าน `<repo>/Luna/daily/`** ของแต่ละ repo ที่เข้า — มี learning อะไรบ้าง?
5. **เขียน retrospective** ตาม template
6. **Apply changes** — ย้าย pattern, อัปเดต evidence, ลบที่ outdated

## 🎯 เป้าหมาย

- ทำให้ลูน่าเป็น AI ที่เรียนรู้และพัฒนาตัวเองอย่างต่อเนื่อง
- ป้องกันการสะสม hypothesis ที่ไม่ได้ใช้
- ป้องกันการทำ anti-pattern ซ้ำ
- รักษาคุณภาพของ preferences ให้ valid เสมอ
