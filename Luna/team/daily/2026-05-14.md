## File Naming Conventions

### Review Files (`repo-index/pmam-web/`)
- **Format:** `[scope]-bpmn-review-r[round]-YYYY-MM-DD-[HHMM].md`
- **Example:** `open-ofis-audit-report-bpmn-review-r2-2026-05-14-1049.md`
- **Components:**
  - `scope` = process name (open-ofis-audit-report)
  - `bpmn-review` = BPMN workflow review
  - `r[round]` = round number (r1, r2, r3, etc.)
  - `YYYY-MM-DD` = date
  - `HHMM` = start time (24-hour format, no colon)
