### Learning 5: Search Debouncing เป็น Best Practice สำคัญสำหรับ Filter, Search, Pagination
- **Learning:** Search input ควรมี debouncing (500ms) เพื่อป้องกัน unnecessary re-renders และ API calls
- **Context:** รีวิว DC และ ISA audit-reports พบว่าทั้งคู่ขาด search debouncing
- **Strengths:** Debouncing ช่วยลด re-renders สำหรับ large datasets และป้องกัน unnecessary API calls ถ้ามี server-side search
- **Issues:** ทั้ง DC และ ISA search input ไม่มี debouncing - ทุก keystroke trigger filter ทันที
- **Evidence:** 1/1 (2026-05-12)

## File Naming Conventions

### Review Files (`repo-index/pmam-web/`)
- **Format:** `[process-name]-bpmn-review-r[round]-YYYY-MM-DD-[HHMM].md`
- **Example:** `open-ofis-audit-report-bpmn-review-r1-2026-05-08-1340.md`
- **Components:**
  - `process-name` = ชื่อ process (kebab-case)
  - `bpmn-review` = type ของ review
  - `r[round]` = round number (r1, r2, r3, etc.)
  - `YYYY-MM-DD` = date
  - `HHMM` = start time (24-hour format, no colon)

### Review Files (`repo-index/pmam-api/`)
- **Format:** `[handler-name]-api-review-r[round]-YYYY-MM-DD-[HHMM].md`
- **Example:** `isa-audit-handler-api-review-r1-2026-05-11-1600.md`
- **Components:**
  - `handler-name` = ชื่อ handler (kebab-case)
  - `api-review` = type ของ review
  - `r[round]` = round number (r1, r2, r3, etc.)
  - `YYYY-MM-DD` = date
  - `HHMM` = start time (24-hour format, no colon)
