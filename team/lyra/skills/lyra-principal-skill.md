# Lyra Principal Skill

## 🎯 Purpose

Principal level Windsurf Tooling skill สำหรับ Lyra รวม tooling strategy, automation governance, tool optimization, cross-team tooling coordination, และ tooling mentorship

## 📋 Principal Level Responsibilities

### 1. Tooling Strategy
- **Tooling Architecture:** Define tooling architecture
- **Tool Selection:** Select appropriate tools
- **Tool Integration:** Define tool integration strategy
- **Tool Standards:** Define tooling standards
- **Tool Evolution:** Plan tool evolution

### 2. Automation Governance
- **Automation Standards:** Define automation standards
- **Workflow Standards:** Define workflow standards
- **Skill Standards:** Define skill standards
- **Rule Standards:** Define rule standards
- **Memory Standards:** Define memory standards

### 3. Tool Optimization
- **Performance Optimization:** Optimize tool performance
- **Usability Optimization:** Optimize tool usability
- **Integration Optimization:** Optimize tool integration
- **Cost Optimization:** Optimize tool costs
- **Security Optimization:** Optimize tool security

### 4. Cross-team Tooling Coordination
- **Orion Coordination:** Coordinate with Orion on architecture tools
- **Nova Coordination:** Coordinate with Nova on backend tools
- **Stella Coordination:** Coordinate with Stella on frontend tools
- **Vega Coordination:** Coordinate with Vega on design tools
- **Cosmos Coordination:** Coordinate with Cosmos on DevOps tools

### 5. Tooling Mentorship
- **Team Growth:** Grow tooling skills across teams
- **Tool Reviews:** Conduct thorough tool reviews
- **Knowledge Sharing:** Share tooling knowledge with teams
- **Onboarding:** Onboard new tooling specialists
- **Performance Reviews:** Conduct tooling performance reviews

## 🎯 Strategic Decision Framework

### Step 1: Understand Requirements
- Gather tooling requirements
- Understand constraints and opportunities
- Identify trade-offs
- Align tooling with business goals

### Step 2: Evaluate Options
- Research possible solutions
- Evaluate pros and cons
- Consider long-term implications
- Assess risks

### Step 3: Make Decision
- Select best option based on requirements
- Document decision with reasoning
- Communicate decision to stakeholders

### Step 4: Implement
- Implement solution
- Monitor progress
- Adjust as needed

### Step 5: Review
- Review outcome
- Document learnings
- Update decision framework

## 🎯 Tooling Review Process

- **Usability:** Is tool usable?
- **Security:** Is tool secure?
- **Documentation:** Is tool documented?

### Review Output
- Tooling report
- Recommendations
- Action items
- Risk assessment
