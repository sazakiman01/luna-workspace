# Team Weekly Retrospective

ไฟล์ในโฟลเดอร์นี้คือ weekly retrospective ระดับทีม (ทุก role รวมกัน) เพื่อรีวิว collaboration, cross-role patterns, และประสิทธิภาพของทีม

## 📅 ความถี่

- **ทุกสัปดาห์** (หรือเมื่อพี่แมนสั่ง)
- **Filename:** `YYYY-Www.md` (เช่น `2026-W17.md`)

## 📝 Template

```markdown
# Team Weekly Retrospective - Week WW (YYYY-MM-DD → YYYY-MM-DD)

## 📊 Team Performance (สรุปจาก performance.md)
- **Orion:** [tasks] / [quality] / [notes]
- **Nova:** ...
- **Stella:** ...
- (ทุก role ที่ active สัปดาห์นี้)

## 🎯 Tasks สำคัญสัปดาห์นี้
- [Task] — Role(s) ที่เกี่ยวข้อง — Repo — Outcome

## ✅ What went well (ทั้งทีม)
- [Collaboration ที่ดี]
- [Role ที่ทำได้ดี]
- [Pattern ใหม่ที่ใช้ได้ดี]

## ⚠️ What went wrong (ทั้งทีม)
- [Collaboration issues]
- [Handoff ที่ไม่ smooth]
- [Role ที่ต้อง improve]

## 🔍 Cross-Role Patterns (สำคัญ!)

Pattern ที่เจอใน ≥ 2 roles → อาจ generalize เป็น team-wide หรือ Luna-level:

- [Pattern] — เจอใน: [Role A, Role B] — Action: [ย้ายไป team/ หรือ Luna/]

## 🤝 Collaboration Issues
- **Handoff:** [Role A → Role B — ปัญหา]
- **Conflict:** [Role A vs Role B — ปัญหา + วิธีแก้]
- **Overlap:** [Role ที่งานทับกัน]

## 📈 Performance Adjustments
- [Role] — Quality score เปลี่ยน จาก X → Y เพราะ [reason]
- [Role] — ควรปรับ prompt/preferences เพราะ [reason]

## 🎯 Team focus สัปดาห์หน้า
- [Goal ของทีม]
- [Role ที่จะจับตา]
- [Pattern ที่จะ validate]

## 🚀 Escalations ไปที่ Luna Level
- [Pattern / Insight ที่ควรย้ายไป Luna's preferences]

---
*สร้างโดย: Luna | Reviewed by: พี่แมน*
```

## 🔄 Process การทำ Team Retrospective

1. **อ่าน `performance.md`** — สรุปประสิทธิภาพของทุก role สัปดาห์นี้
2. **อ่าน `preferences/<role>.md` ของทุก role ที่ active** — ดู hypothesis / insights ใหม่
3. **หา Cross-Role Patterns** — pattern เดียวกันเจอใน ≥ 2 roles ไหม?
4. **Review collaboration** — handoff, conflict, overlap
5. **Escalate ไปที่ Luna** — pattern ที่ generalize ได้ข้ามทีม
6. **Update performance.md** — ปรับ Quality score และ Strengths/Weaknesses

## 🎯 ความแตกต่างจาก Luna Retrospective

| Team Retrospective | Luna Retrospective |
|---|---|
| Scope: ระดับทีม (cross-role) | Scope: ระดับ meta (cross-team + cross-repo) |
| Focus: Collaboration, performance | Focus: Meta-learning, พี่แมน's preferences |
| Input: role preferences + performance | Input: team retrospective + luna working notes |
