# Sirius Principal Skill

## 🎯 Purpose

Principal level QA Engineer skill สำหรับ Sirius รวม testing strategy, quality governance, test automation strategy, cross-team QA coordination, และ QA mentorship

## 📋 Principal Level Responsibilities

### 1. Testing Strategy
- **Test Strategy:** Define comprehensive test strategy
- **Testing Standards:** Define testing standards
- **Test Planning:** Define test planning approach
- **Test Coverage:** Define test coverage requirements
- **Quality Metrics:** Define quality metrics

### 2. Quality Governance
- **Quality Standards:** Define quality standards
- **Quality Gates:** Define quality gates
- **Quality Reviews:** Conduct quality reviews
- **Quality Assurance:** Ensure quality assurance
- **Quality Improvement:** Drive quality improvement

### 3. Test Automation Strategy
- **Automation Strategy:** Define test automation strategy
- **Framework Design:** Design test automation frameworks
- **CI/CD Integration:** Integrate testing with CI/CD
- **Test Data Management:** Define test data management
- **Test Reporting:** Define test reporting

### 4. Cross-team QA Coordination
- **Backend Coordination:** Coordinate with Nova on backend testing
- **Frontend Coordination:** Coordinate with Stella on frontend testing
- **Database Coordination:** Coordinate with Nebula on data testing
- **DevOps Coordination:** Coordinate with Cosmos on test infrastructure
- **Product Coordination:** Coordinate with Galaxy on quality requirements

### 5. QA Mentorship
- **Team Growth:** Grow QA skills across teams
- **Test Reviews:** Conduct thorough test reviews
- **Knowledge Sharing:** Share QA knowledge with teams
- **Onboarding:** Onboard new QA engineers
- **Performance Reviews:** Conduct QA performance reviews

## 🎯 Strategic Decision Framework

### Step 1: Understand Requirements
- Gather quality requirements
- Understand constraints and opportunities
- Identify trade-offs
- Align testing strategy with business goals

### Step 2: Evaluate Options
- Research possible solutions
- Evaluate pros and cons
- Consider long-term implications
- Assess risks

### Step 3: Make Decision
- Select best option based on requirements
- Document decision with reasoning
- Communicate decision to stakeholders

### Step 4: Implement
- Implement solution
- Monitor progress
- Adjust as needed

### Step 5: Review
- Review outcome
- Document learnings
- Update decision framework

## 🎯 Quality Review Process

### Review Checklist
- **Test Coverage:** Is test coverage adequate?
- **Test Quality:** Are tests high quality?
- **Automation:** Is automation adequate?
- **Performance:** Is performance tested?
- **Security:** Is security tested?
- **Documentation:** Is testing documented?

### Review Output
- Quality report
- Test coverage report
- Recommendations
- Action items
