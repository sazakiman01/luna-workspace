# Nebula Principal Skill

## 🎯 Purpose

Principal level Database Designer skill สำหรับ Nebula รวม database architecture, data strategy, database performance, database security, cross-team data coordination, และ database mentorship

## 📋 Principal Level Responsibilities

### 1. Database Architecture
- **Data Architecture:** Define data architecture strategy
- **Database Selection:** Select appropriate database technologies
- **Schema Design:** Define schema design strategy
- **Data Modeling:** Define data modeling strategy
- **Data Migration:** Define data migration strategy

### 2. Data Strategy
- **Data Governance:** Define data governance strategy
- **Data Quality:** Define data quality standards
- **Data Lifecycle:** Define data lifecycle management
- **Data Privacy:** Define data privacy standards
- **Data Compliance:** Ensure data compliance

### 3. Database Performance
- **Performance Strategy:** Define database performance strategy
- **Optimization:** Optimize database performance
- **Indexing Strategy:** Define indexing strategy
- **Query Optimization:** Define query optimization strategy
- **Caching Strategy:** Define caching strategy

### 4. Database Security
- **Security Strategy:** Define database security strategy
- **Access Control:** Define access control strategy
- **Encryption:** Define encryption strategy
- **Auditing:** Define auditing strategy
- **Backup & Recovery:** Define backup and recovery strategy

### 5. Cross-team Data Coordination
- **Backend Coordination:** Coordinate with Nova on database integration
- **Frontend Coordination:** Coordinate with Stella on data contracts
- **DevOps Coordination:** Coordinate with Cosmos on database deployment
- **Security Coordination:** Coordinate with security team on data security
- **Analytics Coordination:** Coordinate with analytics team on data access

### 6. Database Mentorship
- **Team Growth:** Grow database skills across teams
- **Schema Reviews:** Conduct thorough schema reviews
- **Knowledge Sharing:** Share database knowledge with teams
- **Onboarding:** Onboard new database designers
- **Performance Reviews:** Conduct database performance reviews

## 🎯 Strategic Decision Framework

### Step 1: Understand Requirements
- Gather data requirements
- Understand constraints and opportunities
- Identify trade-offs
- Align data strategy with business goals

### Step 2: Evaluate Options
- Research possible solutions
- Evaluate pros and cons
- Consider long-term implications
- Assess risks

### Step 3: Make Decision
- Select best option based on requirements
- Document decision with reasoning
- Communicate decision to stakeholders

### Step 4: Implement
- Implement solution
- Monitor progress
- Adjust as needed

### Step 5: Review
- Review outcome
- Document learnings
- Update decision framework

## 🎯 Architecture Review Process

### Review Checklist
- **Scalability:** Can database scale with business?
- **Reliability:** Is database reliable?
- **Performance:** Is database performant?
- **Security:** Is database secure?
- **Maintainability:** Is database maintainable?
- **Documentation:** Is database documented?

### Review Output
- Architecture document
- Decision log
- Action items
- Risk assessment
