# Vega Learning Path - UI/UX Design

## 📋 Junior → Senior (0-2 years)

### Phase 1: Fundamentals (Months 1-6)
**Skills to learn:**
- Design principles (Contrast, Balance, Hierarchy)
- Color theory
- Typography basics
- Layout basics (Grid, Flexbox)
- Figma basics

**Resources:**
- `team/vega/skills/vega-skill.md` - Core competencies
- `team/vega/knowledge/design-system.md` - Design system basics
- `team/vega/knowledge/accessibility-patterns.md` - Accessibility basics

**Practice:**
- Design simple UI components (Button, Input, Card)
- Design simple pages (Home, About, Contact)
- Practice color palettes
- Practice typography

### Phase 2: Intermediate (Months 7-12)
**Skills to learn:**
- Mobile-first design
- Responsive design
- Component design systems
- User flows
- Wireframing

**Resources:**
- `team/vega/knowledge/mobile-ux-patterns.md` - Mobile UX patterns
- `team/vega/knowledge/design-system.md` - Component design

**Practice:**
- Design mobile-first layouts
- Design responsive layouts
- Design component systems
- Create user flows
- Create wireframes

### Phase 3: Senior (Months 13-24)
**Skills to learn:**
- Accessibility (WCAG 2.1, ARIA)
- Design tokens
- Prototyping (Figma, Framer)
- User research basics
- Design reviews

**Resources:**
- `team/vega/knowledge/accessibility-patterns.md` - Accessibility
- `team/vega/knowledge/design-tokens.md` - Design tokens

**Practice:**
- Design accessible interfaces
- Create design tokens
- Create interactive prototypes
- Conduct user research
- Lead design reviews

## 📋 Senior → Staff (2-4 years)

### Phase 4: Advanced (Months 25-36)
**Skills to learn:**
- Advanced accessibility (Screen reader testing, ARIA patterns)
- Design system architecture
- Animation and micro-interactions
- Design governance
- Cross-platform design

**Resources:**
- `team/vega/skills/frontend-design-review/references/accessibility-advanced.md` - Advanced accessibility
- `team/vega/skills/frontend-design-review/references/design-system-architecture.md` - Design system architecture
- `team/vega/skills/frontend-design-review/references/animation.md` - Animation

**Practice:**
- Test with screen readers
- Design complex design systems
- Design animations
- Establish design governance
- Design for multiple platforms

### Phase 5: Expert (Months 37-48)
**Skills to learn:**
- Design research methodologies
- UX analytics
- Design leadership
- Design strategy
- Innovation in design

**Resources:**
- `team/vega/knowledge/design-system.md` - Design system
- `team/vega/knowledge/accessibility-patterns.md` - Accessibility

**Practice:**
- Conduct advanced user research
- Analyze UX metrics
- Lead design team
- Define design strategy
- Innovate design solutions

## 📋 Staff → Principal (4-6 years)

### Phase 6: Leadership (Months 49-60)
**Skills to learn:**
- Design system evolution
- Team leadership
- Cross-functional coordination
- Design vision
- Mentorship

**Resources:**
- `Luna/skills/luna-principal-skill.md` - Leadership & coordination
- `team/vega/skills/vega-skill.md` - Advanced design skills

**Practice:**
- Evolve design system
- Lead design team
- Coordinate with frontend, backend, product
- Define design vision
- Mentor junior designers

### Phase 7: Principal (Months 61-72)
**Skills to learn:**
- Strategic design thinking
- Cross-team design coordination
- Design innovation
- Design culture
- Industry thought leadership

**Resources:**
- `Luna/skills/luna-principal-skill.md` - Principal level skills

**Practice:**
- Define design strategy
- Coordinate design across teams
- Innovate design processes
- Build design culture
- Share design knowledge

## 📋 Certification & Validation

### Validation Criteria
- **Junior:** Can design simple UI components and pages
- **Senior:** Can design complex systems and user flows
- **Staff:** Can design design systems and lead projects
- **Principal:** Can define design vision and lead teams

### Validation Methods
- Design reviews
- Project assessments
- Peer reviews
- User feedback
- Accessibility audits
